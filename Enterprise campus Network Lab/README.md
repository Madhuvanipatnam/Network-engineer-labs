# Enterprise Campus Network with Dual ISP Connectivity

## Overview

Designed and implemented a three-tier enterprise campus network in GNS3 featuring redundant Layer 3 distribution switches, dual edge routers, dual ISP connectivity, OSPF, HSRP, DHCP, NAT/PAT and eBGP.

The lab demonstrates enterprise-grade routing, gateway redundancy, Layer 2 resilience and end-to-end Internet connectivity.

---

## Technologies

- Cisco IOS
- GNS3
- OSPF
- eBGP
- NAT/PAT
- DHCP
- HSRP
- EtherChannel
- Rapid PVST
